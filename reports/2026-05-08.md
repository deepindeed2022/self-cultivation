3. **跟进 SGLang 中 NVFP4 专家缩放权重加载的修复，验证其对 Blackwell FP4 推理的正确性影响。** 今日 [sgl-project/sglang #24434] 修复了 Nemotron-H 模型加载 NVFP4 检查点时因专家缩放权重键未注册导致的崩溃。这与你的“FP4 量化”和“Blackwell 推理”方向直接相关。建议你阅读该 PR 的代码变更，重点关注专家缩放权重的键注册逻辑。然后，在本地 SGLang 环境中，使用 Nemotron-H 模型的 NVFP4 检查点，对比修复前后模型加载是否成功，并验证推理输出的 logits 一致性，确保 FP4 推理路径的正确性。

4. **研究 TensorRT-LLM 中注意力后端元数据复用修复，评估其对动态形状推理的稳定性影响。** 今日 [NVIDIA/TensorRT-LLM #13696] 修复了注意力后端在请求形状变化时复用陈旧元数据的问题。这与你的“KV Cache 管理”和“推理系统”方向直接相关。建议你阅读该 PR 的代码变更，重点关注元数据验证逻辑的改进（如如何检测形状变化并刷新缓存）。然后，在本地 TensorRT-LLM 环境中，构造一个包含不同序列长度（如 512→4096 tokens）的连续批处理请求，对比修复前后是否出现状态不一致导致的推理错误或性能退化。

5. **评估 SGLang 中 MambaRadixCache 的 KV 事件支持，分析其对 PD 分离路由的潜在价值。** 今日 [sgl-project/sglang #23678] 为 MambaRadixCache 添加了 KV 事件支持，使其能发布缓存放置和驱逐事件供下游路由使用。这与你的“disaggregated prefill/decode”和“KV Cache 管理”方向直接相关。建议你阅读该 PR 的代码变更，重点关注 KV 事件的数据结构（如事件类型、负载）和发布机制。然后，在本地 SGLang 环境中，部署一个 PD 分离配置，观察 MambaRadixCache 发布的 KV 事件，并评估这些事件能否用于优化 prefill 节点到 decode 节点的缓存路由策略。
