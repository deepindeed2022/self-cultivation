## 今日研究方向建议

1. **优先跟进 vLLM [Issue #51744](https://github.com/vllm-project/vllm/issues/51744) 的 Transformers 5.15.0 兼容性崩溃，将其作为你"transformers 版本更新对推理框架兼容性影响"方向的即时验证点。** 该问题导致 vLLM 最新镜像无法启动 Gemma4，直接命中你正在关注的兼容性风险。建议你阅读 issue 中的报错堆栈与讨论，定位是 API 变更还是权重映射问题。然后在本地 vLLM 中，用 `vllm/vllm-openai:latest` 复现该崩溃，对比"固定 Transformers 5.14.x"与"5.15.0"在 Gemma4 启动、预填充和解码阶段的差异，评估该兼容性破坏是否也影响你常用的 Qwen/Mixtral 等模型，并据此决定是否需要在你的推理栈中锁定 transformers 版本。

2. **精读 SGLang [[PR #35719](https://github.com/sgl-project/sglang/pull/35719)](https://github.com/sgl-project/sglang/pull/35719) 的 Qwen3.5 MTP 共享专家权重修复，将其作为你 speculative decoding + MoE dispatch 交叉点的 kernel 级参考。** 该 PR 修复了 AMD MI355X 上 MTP 推测解码丢失融合共享专家权重的问题，恢复约 12% 吞吐，直接关联你关注的 MoE 共享专家与投机采样。建议你阅读其权重融合与恢复逻辑，理解 MTP 在 AMD 后端如何与共享专家交互。然后在本地 SGLang 中，使用 Qwen3.5-35B-A3B 在 MI355X 上对比"修复前"与"修复后"在 MTP 接受率、端到端吞吐和显存占用上的差异，并检查该修复是否同样适用于 NVIDIA 平台的 MTP 路径。

3. **关注 Triton [commit #11387](https://github.com/triton-lang/triton/commit/11387) 的 Hopper/Blackwell FP4 直接 strided 布局转换，将其作为你 FP4 量化 kernel 开发的优化模板。** 该提交消除了全尺寸中间缓冲区，融合解码、逆 tile 置换和 nibble 重打包，直接命中你关注的 FP4 推理与 CUDA kernel 优化。建议你阅读其布局转换逻辑，理解如何避免 FP4 在 Hopper/Blackwell 上的中间内存膨胀。然后在本地 Triton 中，用你现有的 FP4 GEMM kernel 对比"默认布局转换"与"按该提交的 strided 直接写入"在显存占用、kernel 延迟和带宽利用率上的差异，评估该优化是否可迁移到你的自定义 kernel。

4. **结合今日 vLLM [[PR #52157](https://github.com/vllm-project/vllm/pull/52157)](https://github.com/vllm-project/vllm/pull/52157) 的 varlen trtllm-gen decode 支持，将其作为你 adaptive verification 在变长请求场景下的新验证点。** 该 PR 允许每个请求具有不同查询长度，并启用 SM100 上的设备端长度处理，直接关联你关注的 speculative decoding 与 Blackwell 新硬件。建议你阅读其 `cum_seq_lens_q` 和 `max_q_len` 传递逻辑，理解 varlen 如何与 adaptive verification 协同。然后在本地 vLLM 中，使用混合长度请求（如 64/128/256 tokens）对比"固定长度"与"varlen"在 SM100 上的接受率、解码延迟和吞吐差异，重点关注该支持对真实世界变长负载的适应性。

5. **跟进 TensorRT-LLM [[PR #16132](https://github.com/NVIDIA/TensorRT-LLM/pull/16132)](https://github.com/NVIDIA/TensorRT-LLM/pull/16132) 的 `use_host_stop_criteria` 流水线并行修复，将其作为你分布式推理中 PP 通信正确性的检查点。** 该 PR 将标志从 `SampleStateTorch` 移到 `SampleStateTensorsHostTorch`，修复 PP 中未正确传递的问题，直接关联你关注的 TP/PP 分布式推理。建议你阅读其状态
