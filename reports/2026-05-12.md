## 今日研究方向建议

1. **阅读 FlashAttention 的 `fix varlen w/ paging split kv bug` 提交，验证其修复逻辑是否适用于 vLLM / SGLang 中的 PagedAttention 实现。** 该 bug 源于 `set_params_splitkv` 在分页模式下未被调用，导致 `num_splits` 始终为 0。建议你阅读 `flash-attention` 仓库中该 commit 的代码变更，重点关注 `splitkv` 内核的启动参数设置逻辑。然后，在 vLLM 或 SGLang 的 PagedAttention 内核中，检查是否存在类似的 `set_params_splitkv` 未调用问题，并评估该 bug 对变长序列批处理场景下 KV 缓存管理的影响。

2. **跟进 SGLang 的 `Fix Eagle draft decode positions` PR，分析其对 speculative decoding 中位置编码正确性的影响。** 该修复将位置自增从 draft 前移到 draft 后，并调整了 CUDA graph 捕获后的位置恢复。建议你阅读该 PR 的代码变更，重点关注 `EagleDraftWorker` 中位置 ID 的更新顺序。然后，在本地 SGLang 环境中，使用一个支持 Eagle 投机解码的模型，对比修复前后 draft 步骤中 RoPE 位置 ID 的正确性，并评估该修复对解码吞吐和接受率的影响。

3. **研究 vLLM 的 `Apply synthetic mode to probabilistic rejection sampler` PR，评估其对 speculative decoding 中 rejection sampling 模拟精度的影响。** 该 PR 将合成条件概率传递到 rejection 内核，使合成接受率更接近实际拒绝采样。建议你阅读该 PR 的代码变更，重点关注 `probabilistic_rejection_sampler` 内核如何接收合成条件概率。然后，在本地 vLLM 环境中，使用一个支持 speculative decoding 的模型，对比启用/禁用 synthetic mode 时的接受率分布和端到端解码吞吐，量化该修复对性能评估准确性的提升。

4. **分析 SGLang 的 `Deterministic inference backend order on Blackwell` PR，评估其对 Blackwell 上推理稳定性的影响。** 该修复将确定性处理移到注意力后端自动选择之前，避免误报错误。建议你阅读该 PR 的代码变更，重点关注 Blackwell 上注意力后端的选择逻辑。然后，在本地 SGLang 环境中，使用 Blackwell GPU，对比修复前后在连续批处理中不同序列长度下的推理输出一致性，并记录修复对首 token 延迟和吞吐的稳定性影响。

5. **跟进 NVIDIA Model-Optimizer 的 `fix: layerwise calibration backward-compat, recipe split, batch-size guard` PR，评估其对 MoE 模型 FP8/FP4 量化流程的兼容性影响。** 该 PR 将 `nvfp4_experts_only-fp8_kv` 配方拆分为两个，并添加了批量大小保护。建议你阅读该 PR 的代码变更，重点关注配方拆分后的量化参数配置逻辑。然后，在本地 Model-Optimizer 环境中，使用一个 MoE 模型（如 DeepSeek-V4），对比拆分前后 FP8/FP4 量化模型的推理精度（如 perplexity）和显存占用，评估该修复对量化流程稳定性的改进。
