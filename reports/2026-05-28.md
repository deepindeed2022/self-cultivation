3. **研究 vLLM #43205 中 KV 缓存按请求卸载策略的实现，评估其对长序列推理中 KV Cache 管理的优化潜力。** 该 PR 通过 `on_new_request` 生命周期钩子支持块级和请求级卸载策略，直接关联你的分布式 KVCache 优化和推理系统架构方向。建议你阅读 `vllm/vllm/worker/cache_engine.py` 中 `on_new_request` 钩子的实现逻辑，重点关注块级级联卸载策略的触发条件。然后，在本地 vLLM 环境中，使用一个长序列模型（如 LLaMA-3-70B），配置多级卸载（GPU -> CPU），对比启用/禁用该按请求卸载策略时的解码吞吐和显存占用，记录块级卸载策略在不同序列长度下的显存节省效果，并评估其对 continuous batching 场景下调度效率的影响。

4. **跟进 SGLang #24149 中 SPEED-Bench 数据集的支持，评估其对 speculative decoding 算法评估的参考价值。** 该 PR 为 bench_serving 增加了 SPEED-Bench 数据集，用于评估推测解码算法的接受率和吞吐量，直接关联你的 speculative decoding 和性能优化方向。建议你阅读 `sglang/sglang/bench_serving/speed_bench.py` 中数据集的加载和评估逻辑，重点关注 `acceptance_rate` 和 `throughput` 的统计方式。然后，在本地 SGLang 环境中，使用一个支持 speculative decoding 的模型（如 LLaMA-3-8B + EAGLE3），在 SPEED-Bench 数据集上运行 bench_serving，对比不同草稿模型（如 EAGLE3 vs DFlash）的接受率和吞吐量，记录 SPEED-Bench 数据集对评估 speculative decoding 算法的有效性，并评估其对后续算法调优的指导意义。
